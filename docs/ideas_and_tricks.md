# 时间戳
记录了数据的采集时间，为不可更改的时间标记，作为数据验证的依据，用于提交后，区块链程序第一时间验证。确保每次提交到区块链的数据都满足时效性要求，防止不合规的机器人拿自己早期的合规采集的数据充当当前采集的数据。

# 多方共识
在数据采集过程中引入多个独立的参与方，通过共识机制确保数据的一致性。此为上链后的事情，由区块链程序完成。

# 数据可信度评估
对数据源进行可信度评估，确保数据源的可信度和信誉。可以通过验证数据源身份，历史记录和历史信誉值来评估数据源的可信度。

## 身份验证
身份管理，授权，确认。每个机器人都有一个身份ID，每次提交数据，都加密解密

# 数字签名
防止篡改，防止不合规机器人剽窃合规机器人数据用以替换自己不合规行为产生的数据并由此掩盖不合规行为。

# 数据源是否可靠
## 可靠数据
按照合规的行为方式（路线）行动的机器人所提交的数据
## 不可靠数据
按照不合规的行为方式（路线）行动的机器人提交的数据
